## Repository text search

For broad or repeated repository text, literal, regex, and searchable-file discovery in Visual Studio Agent mode, load the `tgrep-search` skill and prefer tgrep when available. Determine the source root from the open solution and repository; preserve the skill's index-readiness, freshness, scope, and fallback rules. Use IDE tools for semantic symbol/reference queries and unsaved editor buffers. Do not install software or change tool permissions as a side effect of a search; do not assume missing indexed results prove absence. If the skill is not discoverable, read `%USERPROFILE%\.copilot\skills\tgrep-search\SKILL.md` if it exists. If it is unavailable, use the existing search tools and state the limitation once.
